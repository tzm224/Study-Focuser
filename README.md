# Study-Focuser 学习专注器应用

这是一个基于网页的学习专注器（番茄钟）应用，旨在帮助用户通过结构化的专注和休息周期来提高学习或工作效率。

## 主要功能

*   **专注/休息周期**：默认设置为90分钟专注学习，然后进行20分钟的长休息。
*   **随机提示与短休息**：在专注期间，每隔5到10分钟会随机触发一次声音提示，提醒用户进行10秒钟的短暂休息。
*   **自定义提示音**：用户可以将自己喜欢的音频文件（MP3格式）命名为 `custom_prompt.mp3` 并替换应用目录下的同名文件，作为随机提示音。
*   **学习周期奖励**：每完成一个完整的“专注+长休息”周期，应用会记录并显示完成的周期数，并伴有奖励提示音。
*   **今日专注时长跟踪**：应用会记录当天累计的专注时间（以小时和分钟显示），并在用户关闭页面时（如果计时器正在运行且有专注记录）弹出提示框显示总结。
*   **提示音试听**：提供“试听提示音”按钮，方便用户在开始计时前检查提示音效果或解锁浏览器音频限制。
*   **状态反馈**：界面上会显示当前所处的阶段（专注、长休息、短休息）以及计时器的状态信息（如：需要用户交互以启用声音、计时开始、计时暂停等）。
*   **本地存储**：完成的周期数和今日专注时长会存储在浏览器的 Local Storage 中，以便在刷新或重新打开页面时保留当天的记录（仅限同一浏览器）。

## 如何使用

1.  **获取文件**：下载包含应用文件的压缩包（例如 `study_timer_final_interval_updated.zip`）并解压缩。
2.  **打开应用**：在解压后的文件夹中，找到 `index.html` 文件，并使用您的网页浏览器（推荐使用 Chrome, Firefox, Edge 等现代浏览器）打开它。
3.  **启用声音（重要！）**：首次打开页面或浏览器限制自动播放声音时，应用会提示“点击任意按钮以启用声音”。请务必先**点击页面上的任意一个按钮**（例如“试听提示音”或“开始”），状态栏会变为“音频已启用”。这是确保所有声音提示能够正常播放的关键步骤。
4.  **开始计时**：点击“开始”按钮，专注计时器将启动。
5.  **控制计时器**：
    *   **暂停**：点击“暂停”按钮可以暂停当前的计时。
    *   **继续**：暂停后，“开始”按钮会重新启用，点击它可以继续计时。
    *   **重置**：点击“重置”按钮会将计时器恢复到初始的90分钟专注状态，并停止当前的计时。
6.  **遵循提示**：应用会自动处理专注、随机提示、短休息和长休息的切换，并通过声音和界面提示您。

## 文件结构

应用主要包含以下文件：

*   `index.html`: 应用的主要结构和内容。
*   `style.css`: 应用的样式和布局。
*   `script.js`: 应用的核心逻辑，包括计时器、状态管理、音频播放等。
*   `custom_prompt.mp3`: 用户自定义的随机提示音文件（默认提供一个示例）。
*   (可能包含其他默认音频文件链接或本地文件，取决于具体实现)

## 自定义提示音

如果您想使用自己的随机提示音：

1.  准备一个 MP3 格式的音频文件。
2.  将其重命名为 `custom_prompt.mp3`。
3.  将这个文件放入与 `index.html` 相同的目录下，替换掉原来的 `custom_prompt.mp3` 文件。
4.  重新加载 `index.html` 页面即可生效。

## 注意事项

*   **浏览器兼容性**：应用设计用于现代网页浏览器。某些旧版浏览器可能不支持所需功能。
*   **音频播放限制**：如“如何使用”部分所述，大多数现代浏览器需要用户先与页面进行交互（点击）才能播放音频。请务必在开始计时前点击一次按钮。
*   **本地存储**：数据存储在浏览器本地，清除浏览器缓存或使用不同浏览器会导致数据丢失。
*   **页面关闭提示**：关闭页面时的专注时长总结提示依赖于浏览器的 `beforeunload` 事件，某些浏览器或设置可能会阻止此提示的显示。
